# Options Strategy Visualizer

Black-Scholes options payoff and scenario explorer. A legs table holds calls, puts, and stock. Up to three scenarios can be overlaid on one chart. An evaluation-date slider shows how the position looks before expiry. The summary reports max profit, max loss, breakevens, and Greeks.

Presets include covered call, poor man's covered call, bull call spread, cash-secured put, collar, and risk reversal, plus an AMZN example. Shareable links encode the full setup in the URL hash.

## Use it

Open the live site: [https://paularute.github.io/options-analyzer/](https://paularute.github.io/options-analyzer/)

Or open `index.html` in a browser on your computer. There is no build step and no install.

Educational tool. Black-Scholes estimates; real prices vary. Not financial advice.
